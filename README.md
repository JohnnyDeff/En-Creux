# EN CREUX

Site éditorial minimaliste construit avec Astro 7.

## Structure

- `src/components/` — composants réutilisables
- `src/content/notes/` — notes éditoriales en Markdown
- `src/content/dossiers/` — dossiers éditoriaux
- `src/content.config.ts` — schémas des collections Astro
- `src/layouts/` — structure globale des pages
- `src/pages/` — routes
- `src/styles/` — charte graphique globale

## Installation

```bash
npm install
npm run dev
```

Pour vérifier le build :

```bash
npm run build
```

## Publication

Le dépôt peut rester connecté à Netlify comme actuellement. Aucun réglage Netlify spécifique n'est requis par cette architecture.
